1. Kaj je diofantska enačba?

Pri običajni enačbi pogosto iščemo poljubno realno število. Pri diofantski enačbi pa iščemo samo celoštevilske rešitve (…, −2, −1, 0, 1, 2, …). Če govorimo o številu predmetov, zahtevamo navadno nenegativna cela števila (0, 1, 2, …).

Običajna linearna enačba

2x = 5

Rešitev: x = 2,5. To je veljavna realna rešitev.

Diofantski pogoj

2x = 5, x ∈ ℤ

Ni celoštevilske rešitve, ker 2,5 ni celo število.

Dve neznanki

3x + 5y = 17

Rešitev je npr. x = 4, y = 1, saj 12 + 5 = 17.

Pomembno: simbol ℤ označuje cela števila. Če naloga govori o kovancih, učencih ali predmetih, negativna količina nima smisla.

Shema: iskanje rešitev

2. Kako rešujemo diofantske enačbe?

Metoda A: smiselno poskušanje in preglednica

Naloga: Imamo kovance po 2 € in 5 €. Skupaj želimo natanko 16 €. Koliko kovancev posamezne vrste lahko uporabimo?

2x + 5y = 16

x pomeni število kovancev po 2 €, y pa število kovancev po 5 €. Velja x ≥ 0, y ≥ 0 in oba sta cela.

Vse možnosti: (x, y) = (8, 0) ali (3, 2). Za y ≥ 4 bi vrednost kovancev po 5 € že presegla 16 €.

Metoda B: izrazimo eno neznanko

3x + 4y = 18

Izrazimo x: x = (18 − 4y) / 3.
Ker sta količini nenegativni, je y lahko 0, 1, 2, 3 ali 4.
Preizkusimo: pri y = 0 dobimo x = 6; pri y = 3 dobimo x = 2. Ostale vrednosti ne dajo celega x.
Rešitvi sta (6, 0) in (2, 3). Preizkus: 3·2 + 4·3 = 18.

Metoda C: deljivost in največji skupni delitelj

Pri enačbi ax + by = c, kjer so a, b, c cela števila, obstajajo celoštevilske rešitve (tudi negativne), natanko tedaj, ko NSD(a, b) deli c.

6x + 9y = 20

NSD(6, 9) = 3. Število 20 ni deljivo s 3, zato ni celoštevilskih rešitev.

6x + 9y = 21

21 je deljivo s 3. Rešitve obstajajo, npr. x = 2, y = 1, saj 12 + 9 = 21.

Pogoj z NSD zagotovi celoštevilske rešitve, ne pa nujno nenegativnih rešitev. Pri predmetih moramo posebej preveriti x ≥ 0 in y ≥ 0.

3. Kako so te enačbe nastale?

Ime so dobile po starogrškem matematiku Diofantu iz Aleksandrije, ki je raziskoval številske probleme in enačbe. Iskanje celoštevilskih rešitev pa se je pojavljalo tudi v starejših matematičnih tradicijah. Danes uporabljamo podobno razmišljanje pri razdeljevanju količin, kombinacijah cen, številskih ugankah in računalništvu.

Pri pouku začnemo s preglednicami in poskušanjem, nato spoznamo deljivost ter sistematične postopke.

4. Besedilne naloge – od besed do enačbe

Naloga: vstopnice za šolsko predstavo

Prodali so 20 vstopnic. Otroška stane 3 €, odrasla 5 €. Skupaj so zbrali 76 €. Koliko je bilo katerih?

Označimo x = število otroških, y = število odraslih vstopnic.
Število vstopnic: x + y = 20.
Skupni izkupiček: 3x + 5y = 76.
Iz prve enačbe: x = 20 − y. Vstavimo: 3(20 − y) + 5y = 76.
60 − 3y + 5y = 76 → 2y = 16 → y = 8. Zato x = 12.
Preizkus: 12 + 8 = 20 in 12·3 + 8·5 = 76. Odgovor: 12 otroških in 8 odraslih vstopnic.

Kako sam sestaviš besedilno nalogo?

Izberi dve vrsti predmetov, določi njuni ceni ali vrednosti, izberi celoštevilski količini in izračunaj skupni znesek. Nato količini skrij in sošolcu ponudi samo podatke o skupnem številu in skupni vrednosti.

5. Kriptaritmi – ko črke predstavljajo števke

Kriptaritem je računska uganka, pri kateri vsaka različna črka pomeni drugo števko od 0 do 9. Ista črka povsod pomeni isto števko. Začetna števka večmestnega števila ne sme biti 0.

Rešen primer

A + A = B

Če je A = 4, potem B = 8, ker 4 + 4 = 8. To je ena možna rešitev, ne edina.

Če dodamo pogoj B = 8, potem je A = 4 edina rešitev.

Pri kriptaritmih pomagajo pravila deljivosti, parnost, seštevanje po stolpcih in sistematično izločanje nemogočih možnosti.

6. Interaktivne vaje

Vnesi celoštevilski odgovor in preveri svoje znanje. Namigi in postopki so pod vsako nalogo.

Ustvari novo nalogo

Pri naključni nalogi zadošča katerakoli nenegativna celoštevilska rešitev.

7. Povzetek za zvezek

Zapomni si

Diofantska enačba zahteva cela števila. V besedilnih nalogah morajo biti količine pogosto tudi nenegativne.

Postopek

1. Določi neznanke.
2. Sestavi enačbo.
3. Poišči možne cele vrednosti.
4. Preveri vse pogoje.
5. Napiši odgovor z enotami.

Pogoste napake

Decimalni odgovor ni celo število. Negativno število predmetov ni smiselno. Ena najdena rešitev še ne pomeni, da drugih ni.
